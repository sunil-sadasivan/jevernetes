Fix boundaries:
- Each admitted persistence transaction gets a five-second deadline detached
  from operator cancellation before Apply begins. Intake/provider work remains
  cancelable; outbox backpressure retries retain the intake context.
- Evidence failure suppresses normal hold, while the admitted queue and final
  report still drain before returning the error.
- Readiness clears in the collector's exit path, before closing its event queue.
- Rejected SPDY bodies permit at most 64 KiB plus one overflow-detection byte.
  Client-go still decodes complete Kubernetes Status bodies, including at the
  exact cap. Oversized bodies produce a fixed error; cleanup closes the socket
  before closing the body to prevent HTTP body draining. Valid upgrade ownership
  remains unchanged. Tests also cover a rejected 101 missing upgrade headers.
- A once-guarded child cancellation runs on every follow worker exit and on
  discovery removal. Repeated retirement tests observe cancellation while the
  parent is alive and reuse a single stream slot over three discovery cycles.

Persistence still fails closed on real storage failures/capacity exhaustion;
this change does not retry arbitrary transaction failures or hide lost storage.
