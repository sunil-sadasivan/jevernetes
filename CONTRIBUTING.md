# Contributing

Use Go 1.25+, Rust 1.94+, Python 3.11+ and Node 20+ for development. Go and Rust binaries run independently; Python is needed only for the retained companion and development fixtures. Run `tools/check.sh` and `tools/release.sh` before proposing changes, plus `cargo fmt --check`, `cargo clippy --locked --all-targets --all-features -- -D warnings`, `cargo test --locked --all-features`, and `python3 tests/rust/tui_pty.py target/debug/jevernetes` after `cargo build --locked`. The executable inventory is `python3 tools/check_parity.py --run`. Unit tests use synthetic evidence, fake Kubernetes clients, in-memory HTTP transports and temporary SQLite files. Never use cluster credentials, live providers, private reports or real notifications in tests.

Keep producer/analysis ownership explicit. Carry `context.Context` across I/O, bound every queue and evidence collection, and join goroutines before returning. Preserve original events when assigning group judgments. A cached judgment must never escape its scope, template/version, generation, safety gate or TTL. Provider schemas reject unknown properties, duplicate keys, missing fields and invalid confidence.

Add focused tests for changed behavior. Do not add an active learning rule merely because a provider suggested it. Reviewed artifacts require independent validation; unknown evidence remains unknown. Persistent controller state contains hashes, counters and typed decisions, never message bodies or readable source metadata.

`tools/check-release.mjs` inspects the intended source tree and optionally compares an archive byte-for-byte. Its diagnostics report filenames and counts, never suspected secret values. `.cache`, local reports, build output and state databases are ignored. Preserve the MIT license and existing media assets.

The Go UI gates run the retained browser fixtures against `internal/investigation/web`, exercise the actual executable over loopback HTTP, and drive its TUI through a PTY. These run from `tools/check.sh` and `tools/release.sh`. Keep the retained frontend/runtime files intact for differential testing; native adapters must preserve literal human-review scopes, original judgments and frozen search references. Full browser rendering is an additional manual check, not implied by Node logic tests.
